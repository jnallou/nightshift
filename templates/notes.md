# Notes for Nightshift

Nightshift reads this file at the start of every shift. Write to it the way you would brief a new teammate. Plain sentences are fine.

Some things worth telling it:

- Parts of the app it should stay away from.
- How you like changes made (small diffs, tests first, naming, and so on).
- What matters most to you right now, so it knows what to pick up first.
- Anything about the backend or services that is not obvious from the code.

Write your notes below this line.
